# Contributing to ADARA AI LAB

## Find the right repository

| If you are working on… | Use |
| --- | --- |
| Web apps, API, services | `adara-platform` |
| Training / inference code | `adara-ai` |
| ASR / TTS interfaces | `adara-speech` |
| Language NLP interfaces | `adara-language` |
| Context engine | `adara-context` |
| Benchmarks | `adara-evals` |
| Client libraries | `adara-sdk` |
| docs.adara.ai content | `adara-docs` |
| Terraform / k8s | `adara-infrastructure` |
| Marketing site | `adaraui` |

Do not copy core AI into product repos. Call the API.

## Process

1. Issue first for non-trivial work
2. Branch from `main`
3. PR with the organization template
4. CI green, then review

## Teams (future)

`@AI-Factory-AI/platform` · `@AI-Factory-AI/ai` · `@AI-Factory-AI/research` · `@AI-Factory-AI/data` · `@AI-Factory-AI/security` · `@AI-Factory-AI/products`

These teams are not created until people exist. Do not invent members.
